# Groove Lab · Main Room 录音版

已内置 Lior 提供的 Main Room Stereo Mix 录音中的 15 个单次鼓击：底鼓、军鼓、闭合踩镲、高音嗵鼓、落地嗵鼓，每件各弱、中、强三档。直接打开 index.html，点击播放即可，无需另行导入或下载音色。

保留连续两小节、四种音符划分、Double、三档力度、一小节预备拍、听练交替、5 BPM 速度吸附、手机横向编辑和节奏分享。每个音符直接播放对应力度的真实录音；Double 播放两次同档采样。

原始录音为 48 kHz / 24-bit 立体声。处理只裁掉前置静音和间隔静音，在尾部低电平处加短淡出，保留鼓击起音、立体声与三档原始响度比例；转为 44.1 kHz / 16-bit WAV 以减小体积。没有逐个归一化、调音或额外均衡。

音频已经嵌入 HTML，本地文件也能播放。HTTPS 部署后可以安装为 PWA。换设备时默认音色随文件携带；自定义音色仅保存在当前浏览器，节奏链接不携带音频。

在线使用：[Groove Lab](https://divinetianci-ltc.github.io/groove-lab/)。在仓库中选择 Code → Download ZIP，解压后打开 index.html 即可本地使用。

兼容旧版一小节分享链接和此前发布的两小节分享链接。

## 检查

运行 node tests/self-check.cjs，检查节奏、采样路由、Double 时序、保存/恢复与启动取消。采样文件本身也经过格式解码、数量、时长、力度峰值与裁切点验证。自动检查未代替手机和电脑的真实设备试听。
