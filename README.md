# Groove Lab · 四小节单行编辑版

在线使用：https://divinetianci-ltc.github.io/groove-lab/

下载电脑离线包：https://divinetianci-ltc.github.io/groove-lab/download.html

Windows 下载 ZIP 后，右键“全部解压缩”，然后双击 Start-Groove-Lab.cmd。启动文件会自动使用 Edge 或 Chrome 打开同目录的 index.html，不安装软件，也不更改系统设置。若浏览器未安装在标准位置，手动打开浏览器，按 Ctrl+O，选择 index.html。

聊天中的 HTML 文件预览可能显示源码；这不是运行应用的界面。请下载后在浏览器中打开。也可将独立 HTML 文件拖到已经打开的 Chrome 或 Edge 窗口。内置的录音不需要联网下载。Windows 启动文件不适用于手机；手机系统的文件预览可能不支持网页交互。

手机使用上方 HTTPS 网页地址。iPhone 在 Safari 中打开，再用“分享 → 添加到主屏幕”创建入口。手机布局将播放和速度固定在底部，节奏选择随滚动保留在上方，半拍选项默认收起，四小节保持横向连续。支持安全区和主屏幕图标。发布说明与手机操作见 GITHUB-PUBLISHING.md。

- 四小节连续排在一条横向编辑区，固定 4/4，八条音轨只显示一次。小节 1–4 按钮可快速跳转；手机左右滑动，音轨名称固定。
- 默认空白只标记拍的位置，先从上方选择 4 分、8 分、16 分、3 连、6 连，之后点音符。待选拍直接使用刚选的节奏并输入该音符，无需反复选拍；每拍仍可单独改变节奏。未选任何节奏时点击会带你到上方选择区。没有为所有拍预先固定一种节奏。
- 整拍对应 1、2、4、3、6 个格子。点击“本小节用此节奏”可一次设置本小节四拍。
- 如需局部变化，切换上方“前半拍”或“后半拍”，再选节奏。半拍内 8 分为 1 格、16 分为 2 格、3 连为 3 格、6 连为 6 格；4 分占整拍，因此半拍模式下不可选。旧版半拍布局继续兼容。
- 改变细分保留全部原有音符。不落在新网格上的位置标记“原”，保持可编辑；该位置所有音轨清空后自动隐藏。
- Double 播放同档声音两次，间隔为该格时长的一半。对于保留的原位置，格时长到下一个显示位置或拍末。
- 点击“复制小节”，选择来源，然后点第 1–4 小节中的目标或“其余全部”，立即复制当前内容。无需粘贴操作；细分、力度、Double 一并复制。覆盖可撤销，最多保留 30 项修改。
- 一小节预备拍；听练交替为四小节鼓循环、四小节节拍器；速度 40–220 BPM，5 BPM 吸附。
- 兼容旧的一、两小节节奏链接；迁移后后续小节留空。新链接包含四小节音符和局部细分，不包含音频。

## 音色进度

八条音轨：踩镲、叮叮镲 Ride、强音镲 Crash、通鼓 1、通鼓 2、军鼓、落地通鼓、底鼓，每件弱、中、强三档，共 24 个独立真实采样。全部来自 2026-10-10 提供的 My Song Stereo Mix.zip 中的 Main Room 录音。

本次录音的三个 MIDI 力度为 25、85、120。没有逐个归一化、移调或额外均衡。沿用四小节版本的播放增益：鬼音 0.42，常规和重音 0.75。相比同一录音使用 0.75 增益，鬼音再降低约 5 dB。

原始文件为 48 kHz、24-bit、双声道，24 个起音均与 MIDI 时间匹配。单次鼓击保留约 2 ms 前置空间，裁掉间隔静音，末端低电平处加 15 ms 淡出；转换为 44.1 kHz、16-bit、双声道 WAV。Ride 保留约 7.5–8.9 秒衰减，Crash 保留约 8.2–10.1 秒衰减。强 Ride 在后一击弱 Crash 开始时残留极低电平尾音，起音检测已排除其干扰，未对录音使用噪声门或降噪。

24 个 WAV 使用 gzip 无损压缩，解压结果与原 WAV 字节相同。网页版先打开小页面，首次播放再并行载入约 5.2 MB 的音频并缓存；采样分块文件有 SHA-256 校验。电脑离线包将相同音频内嵌在约 7 MB 的 HTML 中，使用时不需要联网。两者均不阻塞初次编辑。仅在音频无法解码或导入采样失败时保留原来的合成后备路径，并提示对应问题。解压库 pako 与其 MIT 许可证在 vendor 内。

自定义音色保存在当前浏览器的 IndexedDB，不支持存储时明确提示。本次新鼓组使用独立保存项，旧版存储项保留，不会覆盖新的默认录音。恢复默认鼓组会回到本次 24 个采样。导入整段 Stereo Mix WAV 不会自动切片，请将导出的 ZIP 发回聊天处理。包内保留 24 次击打 MIDI 与 sampling-guide.md。

## 验证和打包

node tests/self-check.cjs 检查待选节奏、上方节奏按钮、整拍/半拍、单行布局、直接复制/撤销、三档力度、Double 时序、四小节播放、预备拍、旧链接迁移、无损解压、采样导入和浏览器存储。tests/browser-check.cjs 在真实 Chromium 中检查 1440、390、320 px 的加载、鼠标点击、触控、横向滑动、四拍输入、复制、真实音频解码与刷新保留。运行此可选检查需安装 Playwright 和其 Chromium，或通过 GROOVE_BROWSER_EXECUTABLE 指定本机浏览器。自动检查不代替实际设备的试听，尚未在 Safari 引擎中实测。

完整包同时包含源码和 build.py。安装 Python 3 后运行 python3 build.py 可重新生成内嵌音频的单文件网页与 ZIP；音频从 index.html 或其引用的 audio 文件读取，不需要原始长录音或第三方依赖。再运行 python3 build_web.py 可在项目的相邻 groove-lab-web 目录生成供 Pages 使用的小文件版本和下载包分块。sample-report.json 记录时长、裁切、峰值和哈希。prepare_samples.py 是本次音频裁切源码，仅重新处理长录音时需要 NumPy 与 SciPy。
